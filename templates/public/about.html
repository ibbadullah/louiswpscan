{% trans "Who we are" %}

{% blocktrans %}Louis WP Scan is a non profit project created after one too many small websites were lost to attacks that were entirely preventable. WordPress powers a huge part of the web, from family blogs to local shops and charities. Many of these sites are run by people who are experts in their own field but were never meant to become security specialists.{% endblocktrans %}

{% blocktrans %}We exist to close that gap. We turn the technical checks a security professional would run into a simple, friendly report that anyone can act on.{% endblocktrans %}
